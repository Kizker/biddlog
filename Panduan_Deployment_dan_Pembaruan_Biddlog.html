1. Alur Kerja Rutin Saat Ada Pembaruan (Workflow Cepat)

Setiap kali Anda selesai mengubah kode di laptop/komputer lokal dan ingin menerapkannya ke website live, ikuti 2 tahap sederhana berikut:

A
Di Komputer Lokal (Mac / PC): Simpan & Push ke GitHub

Pastikan Anda sudah mengompilasi frontend React dan melakukan push ke branch main:

# 1. Masuk ke folder dashboard dan build frontend jika ada perubahan UI
cd biddlog_legacy/dashboard
npm run build
cd ../..

# 2. Commit dan push ke GitHub
git add .
git commit -m "Update fitur atau perbaikan terbaru"
git push origin main
B
Di Server Hostinger: Terapkan Pembaruan (1 Baris Perintah)

Buka terminal, login SSH ke server, dan jalankan skrip deploy otomatis yang sudah disediakan:

# 1. Login SSH
ssh -p 65002 u141095167@46.202.138.88

# 2. Masuk direktori & jalankan deploy script
cd ~/domains/biddlog.site/public_html
bash deploy.sh
💡
Perintah bash deploy.sh akan secara otomatis menarik kode terbaru dari GitHub, mereset cache, dan mengatur izin folder yang diperlukan.

2. Prosedur Pembaruan Manual (Jika Tanpa Script)

Jika Anda ingin menjalankan pembaruan langkah demi langkah secara manual di terminal server:

# 1. Masuk ke folder proyek di server
cd ~/domains/biddlog.site/public_html

# 2. Ambil update dari GitHub (menghindari conflict)
git fetch origin main
git reset --hard origin/main
git pull origin main

# 3. Berikan hak akses folder storage & database
chmod -R 775 storage bootstrap/cache database
